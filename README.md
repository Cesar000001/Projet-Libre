# Le Bestiaire des Pyrénées

Un bestiaire interactif des animaux des Pyrénées. En faisant défiler la page, on monte la montagne de la vallée aux sommets, à travers les étages forestier, subalpin et alpin, à la rencontre du desman, de l'isard, du gypaète barbu et des autres.

Réalisé en HTML, CSS et JavaScript, avec [Vite](https://vite.dev/) et [GSAP](https://gsap.com/).

## Lancer le projet

Il faut avoir installé [Node.js](https://nodejs.org/).

```bash
npm install     # installe les dépendances (une seule fois)
npm run dev     # lance le site en local
```

Ouvre ensuite l'adresse affichée dans le terminal (en général http://localhost:5173).

Pour générer la version en ligne du site : `npm run build` (le résultat est dans `dist/`).
